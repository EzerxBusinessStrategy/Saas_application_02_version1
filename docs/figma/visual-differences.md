# Visual differences

The 1660×2318 Figma frame was inspected through Figma MCP. This implementation applies its system values to the existing multi-tenant dashboard rather than replacing it with TailAdmin's demo analytics content.

Known intentional differences: the local tenant mark replaces the TailAdmin logo; role-specific data and routes replace the sample analytics tables; and the mobile sheet/table behavior is inferred because the inspected frame is desktop-only. A browser screenshot comparison remains required when a target workspace and mobile Figma frame are selected.
